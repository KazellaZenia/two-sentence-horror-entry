A two-sentence horror story (232 characters) for make.fun's Two-Sentence Horror bounty: a gardener's soil keeps returning buttons, and this year they come from the shirt he is wearing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

`main.ts` writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` and nothing else. The story is checked in code before it is written: exactly two sentences, 1–400 characters, no leading or trailing whitespace — otherwise the program throws. The file is read back after the write to prove what is on disk is exactly the story.
